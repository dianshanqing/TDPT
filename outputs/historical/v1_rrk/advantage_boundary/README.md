# Reduced-kernel cost comparison

The original table compares the analytic Bernoulli history requirement with the ideal and observed fixed-depth RRK call counts. Use the five statevector runs in the parent folder to recover the powers and integer counts. Columns referring to full-size detector reach are auxiliary comparisons of the historical finite-bond settings. The ratio measures calls under the specified known-target design, without hardware execution time or a full transport circuit.
