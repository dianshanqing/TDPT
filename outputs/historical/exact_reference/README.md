# Historical deterministic duct reference

The five runs save finite-step terminal probabilities, first-termination increments, active state counts, and the comparison to the corresponding analog MC batch. Each file ends at its named step (3, 7, 10, 12 or 15). Their shared prefixes are the same physical process. All detector rows were checked against the full-size duct reference to within 1e-13 absolute difference. The historical solver under `../v1_inputs/tools` uses the archived v1 physical configuration.
